# 부산 신용보증 월별 통계 대시보드

별도 서버나 빌드 과정 없이 실행되는 HTML/CSS/JavaScript 정적 대시보드입니다.

## 실행

`index.html`을 더블클릭하여 브라우저에서 엽니다. 인터넷 연결 없이도 동작합니다.

## 매월 데이터 교체

화면 코드와 데이터는 분리되어 있습니다. `data/dashboard-data.js`의 값만 갱신하면 됩니다.

- `meta`: 기준일 및 표시 문구
- `monthly`: 월별 통계
- `district`: 구·군별 통계
- `age`: 연령대별 통계
- `industry`: 업종별 통계

분류별 배열 형식은 `[구분명, 신규보증, 사고발생, 사고발생 순증률, 보증잔액]`이며 금액 단위는 억원입니다.

> 브라우저 보안 정책상 로컬 HTML이 외부 JSON 파일을 직접 읽으려면 서버가 필요합니다. 별도 서버 없이 실행하기 위해 데이터만 독립 JavaScript 파일로 분리했습니다.
