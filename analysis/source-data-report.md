## 2. 발견한 주요 지표와 분류

- 신규보증: 건수, 금액
- 사고: 순증 건수, 순증 금액
- 보증잔액: 건수, 금액
- 지역: 시도, 시군구
- 업종: 대분류, 중분류, 상세 업종
- 대표자 연령대: 원본 10년 단위 구간을 대시보드에서 5개 구간으로 재분류
- 업력: 원본 구간값 유지
- 부산 구·군: 16개 전체 확인
- 업종 대분류: 20개 확인

`보증공급`이라는 독립 열은 없다. `보증_실행(신규보증)`은 보증공급과 동일시하지 않고 `신규보증 실행`으로 표시한다.

금액 단위는 모두 백만원이다.

사고발생 순증률은 다음 산식으로 계산한다.

`{연초~기준월 사고순증금액 누계 / 당월말 보증잔액} × {365 / 누적일수} × 100`

원본의 `보증_사고_순증_금액`을 월별 사고발생액-정상화액으로 사용하며, 해당 연도 1월부터 기준월까지 누적한다. 누적일수는 1월 1일부터 기준월 말일까지의 경과일수로 계산하고 연환산 기준일수는 윤년에도 365일을 고정 적용한다.

## 3. 표준화 구조

표준 행의 기준은 `기준월 × 지역 × 업종 × 대표자연령대 × 업력`이다.

| 표준 필드 | 원본 명칭 | 형식 |
|---|---|---|
| period | 기준년월 / 잔액 파일명의 YYMM | YYYY-MM |
| province | 시도명 | 문자열 |
| district | 시군구명 | 문자열 |
| industry_major | 업종구분대분류 | 문자열 |
| industry_middle | 업종구분중분류 | 문자열 |
| industry_detail | 업종명 | 문자열 |
| age_group | 대표자연령대 | 문자열 |
| business_age | 업력 | 문자열 |
| new_guarantee_count | 보증_실행(신규보증)_건수 | 정수 |
| new_guarantee_amount | 보증_실행(신규보증)_금액 | 숫자(백만원) |
| accident_net_count | 보증_사고_순증_건수 | 정수 |
| accident_net_amount | 보증_사고_순증_금액 | 숫자(백만원) |
| guarantee_balance_count | 보증_잔액_건수 | 정수 |
| guarantee_balance_amount | 보증_잔액_금액 | 숫자(백만원) |
| accident_rate | 위 산식으로 계산 | 숫자(%) |

열 이름 매핑과 필수 열 목록은 `config/data-standardization.json`에서 관리한다. 원본 연령대는 표준 행에 그대로 보존하고, 대시보드 집계에서 `20대 이하`, `30대`, `40대`, `50대`, `60대 이상`으로 재분류한다.

## 4. 자동 업데이트 방식

`scripts/transform_dashboard_data.py`는 실행할 때마다 ZIP 전체를 새로 검색한다.

1. 원본 ZIP의 SHA-256 기록
2. 임시 폴더에 작업용 사본 추출
3. 잔액 파일명의 `YYMM`을 기준월로 변환
4. 사고 파일의 `기준년월` 또는 월별 파일명을 `YYYY-MM`으로 변환
5. 생략된 계층값을 앞 행 기준으로 복원
6. 지역 제한 없이 전체 원본 행을 표준화 및 공통 집계
7. 구군별 집계에만 부산 16개 구·군 필터 적용하고, 월별·연령대별·업종별·업력별은 전체 지역 집계
8. 대시보드 JSON과 전체 이력 JSON 생성
9. 파일별·전체 행 수 및 지표 합계 대사
10. 작업 후 원본 ZIP SHA-256 재확인

기본 실행:

```bash
python scripts/transform_dashboard_data.py "source/5개년 자료.zip"
```

생성 파일:

- `data/generated/dashboard-data.json`: 현재 대시보드 형식
- `data/generated/dashboard-history.json`: 5개년 월·분류별 전체 집계
- `data/generated/validation-report.json`: 파일별·전체 검증 결과

검증 후 운영용 JSON까지 교체하려면 `--publish-dashboard` 옵션을 추가한다. 원본과 동일한 표준 행 CSV가 필요하면 `--normalized-csv` 옵션을 추가한다.

## 6. 향후 월별 파일 처리

- 앞으로 잔액과 사고 자료는 월별 파일 단위로 추가한다.
- 변환기는 파일명 끝의 `_YYMM.xlsx`, `_YYYYMM.xlsx`, `_YYYY-MM.xlsx`를 자동 인식한다.
- 동일 기준월 파일이 둘 이상이면 중복 집계를 방지하기 위해 오류로 중단한다.
- 월별 사고 파일이 존재하면 기존 누적형 사고 파일은 제외하고 경고를 남긴다.
- 첫 신규 월별 사고 파일을 받을 때 실제 파일명과 열 구성이 예상 규칙과 같은지 한 번 확인해야 한다.
